# Summary

Cost Query Pro (CQP) grew from an idea I began exploring in early 2025: engineering firms already possess valuable historical construction cost data, but turning that data into usable intelligence is surprisingly difficult.

I began building CQP in July 2025 to explore how historical bid tabs, estimates, and project records could be normalized, validated, and searched using natural language. The project tackles real-world challenges such as inconsistent units and descriptions, project metadata buried in headers and footers, messy spreadsheets, and incomplete records.

At its core is a simple principle: the LLM translates and narrates; the application computes. AI helps interpret engineering language, while deterministic code performs the actual searches and calculations.

The goal is to transform existing project history into traceable, defensible information that engineers can use to make better decisions.
